## 图片与视频的共用设计

### 用户确认的修改边界（2026-10-22）

仅替换“在线调用”页签内的工作台（用户截图红框）。站点导航、返回入口、模型简介/能力/价格区、在线调用/接入说明页签、底部三步接入的布局统一沿用文字页；模型名、类型、价格单位及接口说明内容按真实模型变化，不额外设计一套外围页面。

文字调用区保持约 1:1；图片/视频调用区采用左配置约 35%、右预览约 65%，共享相同左右外边缘。窄屏先配置再预览。左栏参数较长时支持内部滚动，生成按钮在配置栏底部保持可达；键盘焦点和校验提示不能被底部按钮遮挡。

已实际查看参考页的 Playground，未提交生成或登录：

- [Seedance 2.5](https://evolink.ai/seedance-2-5)：模式选择、表单/JSON、提示词、时长、分辨率、画幅、音频；右侧视频预览/JSON 和历史。参考截图：[视频调用区](seedance-playground-reference.png)。
- [GPT Image 2](https://evolink.ai/gpt-image-2)：提示词、参考图上传、尺寸/比例、分辨率、质量、背景和高级参数；右侧图片预览/JSON、放大、下载及历史。参考截图：[图片调用区](image-playground-reference.png)。

首版应精简：图片保留提示词、参考图、比例/尺寸、质量、数量；视频保留模式、提示词、按模式出现的素材输入、时长、分辨率、画幅、音频。JSON、高级参数和历史默认收起或置于次级入口。不得照搬参考页的计费承诺、价格或具体参数上限。

状态必须区分未生成、上传、排队、生成中、成功和失败。无真实进度时只显示状态，不虚构百分比；失败保留输入可重试。预览尺寸与画幅联动。实际参数以平台接入能力为准，待对应媒体任务接口完成后才启用真实提交。

沿用已选定的文字工作台，不新增营销长页或评分圆环。保留模型名、供应商、主要能力和简短说明；上方紧凑价格区；主区域左侧配置、右侧预览；接入说明独立切换。未登录点击生成进入登录并返回当前模型页。实际支持参数来自平台模型能力配置，不能照搬参考站支持范围。

### 图片生成

- 左栏：提示词必填；参考图可选；尺寸/比例、质量和数量作为主要参数；高级参数默认收起。编辑能力和蒙版仅在目标模型支持时显示。
- 右栏：空态、上传中、排队、生成中、成功、失败；成功后展示图片和下载入口，保留参数及任务标识。
- 接入说明：创建任务、查询状态、结果获取与失败处理。当前未有图片后端，先定义契约及状态，再接适配器；不能向 Chat 端点发送图片生成请求冒充支持。
- 文件上传应校验 MIME/大小，使用受控对象存储和有期限的链接；真实图片不会通过演示结果代替。

参考：[GPT Image 2.5 Sunburst](https://evolink.ai/gpt-image-2-5-sunburst)。仅参考信息层级与图片输入/预览流程，不采用其售价、模型参数上限或可用性承诺。

### 视频生成

- 左栏：提示词、生成模式；按能力显示参考图片或视频输入；时长、画幅、分辨率为主要参数，音频开关仅在支持时显示。
- 右栏：排队/生成进度状态、失败提示、成功播放器与下载入口。没有供应商进度时显示状态，不虚构完成百分比。
- 后端使用异步任务，明确任务归属、轮询/回调、超时、取消、重复回调幂等、费用预占与结算。
- 接入说明展示创建任务与查询任务两个阶段；刷新页面可恢复本人任务，不能泄露其他工作区结果。

参考：[Seedance 2.5](https://evolink.ai/seedance-2-5)。仅参考模式/输入/参数/结果结构，实际能力和定价由平台接入供应商后确认。

图片/视频当前状态：设计范围已定义，页面实现、媒体接口和真实生成联调待开发。

## 后续统一开发：管理后台控制上架与价格

按用户要求，此部分列入后续迭代，本轮不直接实施。

### 已有基础

- 模型目录 `ModelsRepository.list` 已筛选 isEnabled；管理端已有启停、推荐和状态修改。
- 数据库已有 inputPrice/outputPrice/priceUnit，公共目录由数据库映射价格。
- 前端仍有静态推荐和演示回退；后台尚未形成完整价格编辑、发布和历史版本闭环。

### 待开发

1. 管理后台编辑模型资料、能力、售价及计价单位，区分供应商成本和客户售价；仅平台管理员可发布，工作区配置不能覆盖平台售价。
2. 统一上架状态对模型广场、详情、首页推荐、排行榜、工作区可选列表和调用入口的影响；下架模型不可通过直链或既有工作区配置继续调用。
3. 公共页面采用后端目录为事实来源。生产环境 API 失败时展示失败/重试，不用旧演示模型或演示价格冒充在线数据；本地演示模式显式标识。
4. 发布价格版本，定义生效时间、币种、输入/输出/缓存或任务维度；历史用量绑定当时价格快照。不能直接覆盖历史账单计算依据。
5. 价格单位按模型类型展示：Token、张、秒、字符等依真实计价规则确认。展示币种与账本结算币种区分；需要换汇时另设汇率来源与版本。
6. 发布后使目录/详情/推荐缓存失效；工作区切换和价格更新后不复用旧缓存；上下架和改价追加审计。

### 验收

- 管理员下架后，广场、推荐和搜索不再出现；直链明确不可用，推理拒绝；重新上架后恢复。
- 修改价格并发布后，广场、详情、调用说明展示一致；计费使用正确生效版本；发布前后的请求分别可追溯。
- 非管理员改价返回 403；负价、非法单位和价格精度校验拒绝；重复发布不产生重复版本。
- 后端离线不会重新显示已下架模型或演示价格；旧标签页刷新后能得到最新状态。

## 建议下一步

先补齐平台模型资料与能力契约、上下架展示闭环，再一起开发价格版本/计费关联及图片视频任务接口，避免分别硬编码页面参数和价格。
