## 平台工程与安全

工作区 API IP 允许列表：设置页可保存开关及最多 100 项 IPv4/IPv6/CIDR，Owner/Admin 可修改；仅约束 API Key 接口，控制台保留恢复入口。Fastify 默认不信任转发头，只有 `TRUSTED_PROXY_CIDRS` 中的代理地址段可以参与真实客户端 IP 解析，API Key 允许列表统一使用该结果。伪造 `X-Forwarded-For`、可信代理链和非法 CIDR 均有专项测试。原静态审计开关已移除；管理端操作审计与全局会话管理已完成第一阶段，工作区领域事件审计仍待开发。

分布式流量治理：Redis Lua 脚本提供多实例共享的全局 IP 限流、登录 IP/账户双维度限流和工作区模型 RPM；推理入口使用带心跳和过期恢复的工作区并发租约，普通响应、流式结束、取消及异常都会释放容量。超限统一返回 429 与 `Retry-After`，Redis 不可用返回 503；请求体默认限制为 1 MiB，readiness 同时检查 PostgreSQL 与 Redis。双实例共享额度、并发拒绝、租约恢复、流式释放、可信代理和大请求 413 均已验证。

工作区权限矩阵：`WorkspaceContextGuard` 在解析服务端工作区上下文后，统一读取控制器声明的权限并按角色授权。Owner/Admin 拥有全部权限；Developer 可管理模型、路由和密钥并使用在线调用；Billing 只读取工作区、成员和用量；Viewer 只读工作区、成员、模型、路由和用量。成员管理继续保留所有者、自身与 Admin 层级保护。五种角色对 14 项权限的真实 PostgreSQL 集成测试通过。

实时撤权与竞态保护：`JwtAuthGuard` 在验证签名后按 `sid + sub` 读取有效会话和用户最新状态，以数据库中的邮箱、平台角色覆盖令牌快照；会话撤销、密码重置、账户停用和平台角色修改从下一次请求生效。API Key 创建在事务内锁定工作区，随后重查成员身份、权限和有效密钥上限；成员移除/降权使用同一把锁并撤销密钥，因此无论竞态顺序如何都不会留下可用密钥。两组真实 PostgreSQL 集成测试覆盖即时撤权及 12 轮移除竞态、降权竞态和鉴权兜底。
